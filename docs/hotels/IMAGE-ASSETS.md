# Hotel workspace brand image

`public/images/hotel-owner-lounge.webp` is an AI-generated, fictional boutique-hotel lounge image created for the TravelOS hotel workspace. It is decorative brand artwork, not a verified property photo or a marketplace listing. The UI labels it as illustrative; no hotel listing or room availability is implied.

The generated original remains outside the repository in the workspace's generated_images directory. The checked-in WebP is an optimized encoding of that original. The shared `hotel-brand.tsx` component uses Next Image with responsive sizes, an explicit layout area, a blur placeholder and a visible caption. No remote photo service or third-party tracking request is needed to display it.

The owner and operator consoles share the existing site font stack, blue action colour, navy text, rounded surfaces and brand navigation. This visual update does not enable any pending booking/payment/AI functionality or change access permissions.
